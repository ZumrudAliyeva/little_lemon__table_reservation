# 🍽 Little Lemon — Table Reservation System

A responsive table reservation interface built as the final project of the Meta Front-End Developer Professional Certificate.

## 🚀 Overview

This project focuses on building a user-friendly reservation system with form validation and structured user interaction.

## ✨ Features

- Table reservation form
- Form validation and error handling
- Responsive UI design
- User-friendly booking flow

## 🧠 What I focused on

- Creating intuitive form interactions
- Managing form state and validation logic
- Improving usability through clear structure and feedback
- Building a clean and responsive UI

## 🛠 Tech Stack

React, JavaScript, HTML5, CSS3  

## 📌 Highlights

- Strong focus on UX and form usability
- Structured validation logic
- Clean component-based architecture
